Social Perks is a San Francisco‑based platform that enables businesses to turn their happiest customers into marketing advocates. By rewarding customers for sharing posts, reviews, and referrals across 15 social platforms, the service provides authentic word‑of‑mouth promotion while handling FTC compliance, fraud detection, and analytics. The platform offers tiered campaigns, a dashboard for managing rewards, and API access for integration.

**Areas:** Marketing · Social Media · Customer Loyalty · SaaS · San Francisco

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Social Perks: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
